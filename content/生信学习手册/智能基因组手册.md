## 常见的测序类型

### DNA信息层次

#### DNA序列与可及性信息

1：DNA-seq
**功能**：可以看==DNA序列信息==，可以看突变和==SNP位点==，是DNA层面最基本的信息
**流程**：打断DNA片段——测序——比对read(read是读的片段
coverage是指某个位置有多少reads覆盖到，也就是被测到的次数)
**输出结果**：一个VCF（染色体位置，REF，ALT，样本基因型）REF为参考基因型，ALT为突变
                                Chr1   100   A   G   0/1
                最终还可以把0/1→1 变成基因型剂量矩阵
2：ATAC-seq
    **功能**：找到基因组中==可及性==比较高的DNA片段
    **流程**：利用Tn5转座酶切割DNA可及片段——接入插头——测序——比对到基因组——统计read在哪些区域集中——确定开放染色质区域
    **输出结果**：连续可及性轨迹，peak为峰值比较高的区间，即开放染色质区域
3：WGBS （Whole-Genome Bisulfite Sequencing）
    **功能**：在胞嘧啶位点估计==甲基化状态==
    **原理**：亚硫酸氢盐处理会使未甲基化的 C 发生转换，而甲基化的 C 在这种处理下保留下来。测DNA序列中C的含量和位置就可以知道甲基化比例和位置
    **输出结果**：chr    position coverage mythylated mythylation（甲基化比例）
             Chr1     100          30               25                83%

#### DNA与蛋白互作层次

- 4：ChIP-seq
  - **功能**：ChIP-seq通过抗体富集形成==蛋白结合或修饰区间==证据，找到某个特定蛋白，或者某种组蛋白修饰，在哪里
  - **流程**：DNA蛋白交联——打碎DNA——抗体富集——测序与比对——对照矫正——峰检测
  - DNA与蛋白先固定，然后找到一个这个蛋白的特异抗体，抗体结合到蛋白因此定位到DNA，测序后就定位到抗体所在位置，找到峰区。DNA本身可能存在非特异性富集，所以需要input（不经特异性抗体富集的对照样本，可以帮助排出背景）
  - **输出结果**：峰，区间，信号轨迹
- 5：CUT\&Tag
  - **功能**：==更聪明的ChIP-seq==，先用抗体结合蛋白，让酶就在它附近切 DNA 并加上测序接头。
  - **原理**：抗体上有复合的Tn5转座酶，直接到目标附近切，而不是大面积乱切，切完后加上测序接头，==以靶向切割和接头化提高局部信号==
  - **输出结果**：区间 + coverage track + peaks
- 6：DAP-seq （DNA Affinity Purification）
  - **功能**：描绘==体外蛋白==—DNA结合偏好，主要关心一个转录因子或其他蛋白在体外倾向于结合什么DNA序列。**可以帮助你发现： 结合区域，候选 motif，转录因子的 DNA sequence preference**
  - **流程**：大量 DNA——固定到载体/芯片上——加入 TF——TF 和它喜欢的 DNA 结合——洗掉没有结合的 DNA——把结合 DNA 回收——测序
  - **输出结果**：序列，但是注意体外结合偏好≠体内真实结合状态

#### DNA的空间关系

- 7：Hi-C
  - **功能**：研究基因组的==三维空间组织==，例如两个调控区域是否存在空间接触，以及染色质结构如何发生变化。Hi-C 将这些空间接触固定、切割并连接近邻 DNA 片段，再对连接产物测序，从而得到成对的基因组坐标。
  - **核心流程**：固定空间接触 → 切割 → 近邻连接 → 测序 → 得到成对坐标 → 统计接触频率。
  - **输出结果**：DNA-DNA contact pairs 和 contact matrix（接触矩阵）

### RNA信息层次

#### RNA表达信息

8：RNA-seq
    **功能**：测量==转录对象的相对丰度==，回答哪些基因在表达，表达多少的问题
    **流程**：RNA逆转录——cDNA建库——测序——比对
    **结果**：表达矩阵
    ![[Pasted image 20260917233842.png]]
9：Ribo-seq
    **功能**：研究哪些 RNA ==正在被核糖体翻译==，以及核糖体在 RNA 上的分布。Ribo-seq（Ribosome profiling）利用翻译过程中核糖体保护的一小段 RNA。去除未被核糖体保护的 RNA，保留核糖体保护片段并进行测序。
    **核心流程**：核糖体保护片段 → 读段比对 → P位点推断 → 占据轨迹 → 基因/开放阅读框翻译量评估
    **结果**：ribosome footprint、核糖体占据轨迹、翻译区域和可能的开放阅读框信息。
10：DART-seq
    **功能**：以邻近编辑事件支持 RNA 修饰位点推断，看RNA 上有没有发生==特定位点的编辑==
    **原理**：利用一个RNA结合模块YTH找到特定RNA，编辑酶APOBEC负责进行邻近位点碱基编辑。我们直接看不到 m6A，那就让识别 m6A 的蛋白带着编辑酶，在 m6A **附近**把 C 改成 U；测序时就看到 C→T，这个变化相当于给 m6A 打了一个可检测的标签。
    **结果**：位点状态 + 编辑比例 + 覆盖证据
11：STRIPE-seq
    **功能**：以单碱基精度捕获转录起始事件，看转录从哪一个碱基开始。发现TSS。
    **原理**：STRIPE-seq先用TEX减少没有5′ cap的RNA，再利用逆转录酶到达m⁷G cap附近时产生的非模板C，通过TSO进行template switching，把RNA的5′端接入测序文库；因为read的起始位置对应RNA的5′端，所以把read比对到基因组后，就能把TSS定位到单个碱基。
    **结果**：知道了TSS位点

## 基因组文件格式与坐标体系

### 类型

1：FASTA 序列本体
    promoter\_001 ATGCAATCGGATCCGTTACGATGC
    第一行以 > 开始，保存序列标识符。后续行保存 A/C/G/T/N 等序列字符。可保存染色体、基因、转录本、启动子或 固定窗口。
    ==注意==：序列方向、参考基因组版本、N的处理和ID对齐，都会影响后续模型
2:FASTQ  序列加单碱基测序质量
    ![[Pasted image 20260918100747.png|258]]
3：VCF 记录变异与样本基因型
    ![[Pasted image 20260918101008.png]]
    剂量编码后续还可以构建基因型矩阵
4：BED 记录基因组区间
    ![[Pasted image 20260918101147.png]]
    ==注意！==
    BED的坐标与VCF不同
    BED是0-base，`[start,end)` 左闭右开
    VCF是1-base，单个位点位置
    0-base意味着第1-5的碱基，在python中对应BED坐标是`[0,5)`。是一种更符合python计算的一种坐标，碱基总数就等于5-0=5。学过python应该可以理解这个坐标
5：GFF/GTF 记录基因，转录本和外显子层级
    通常记录gene，transcript，exon，CDS，UTR
6：bigWig 沿基因组变化的连续信号
    ![[Pasted image 20260918102114.png]]
    在许多调控模型中： FASTA 提供输入序列；BED定义窗口；bigWig或矩阵化信号提供输出y

## 模型数据表示

### 正常数据

在导入模型之前，数据表示形式决定了模型关注什么舍弃什么信息
一段DNA信息大致有以下几种表示形式，包含信息量逐渐增加

- 1：GC含量    用途：QC，baseline
  - GC含量 = G和C在序列中的比例
  - 优点：计算简单，可作为baseline模型数据
  - 缺点：**几乎完全丢失了序列的顺序和位置信息。**
- 2：K-mer    用途：传统机器学习
  - k-mer就是长度为k的连续序列片段。k-mer本质上只是计算上的序列切片，不等于基因，也不天然等于功能元件。可以统计一条DNA序列中每种k-mer出现的次数或频率。
  - 比如3-mer就是3个碱基为一个片段,==逐个碱基变化==，实际不符合生物密码子三个碱基一个单位。比如AGG CGT各自出现的频率，最后会在建模过程中被转化为一个向量比如AGG`[0.02, 0.00, 0.05, ...]`
  - 特征空间维度 = 4^k，比如3-mer，就有64种，是一个64维的向量
  - 优点：可以捕获一定的特征，可作为baseline
  - 缺点：会弱化精确位置，长程顺序，更复杂的上下文关系
  - k-mer≠motif，k-mer有可能切到的是具有生物学功能的motif
- 3：One-hot编码    用途：CNN，序列模型
  - one-hot编码不再把整条DNA压缩成一个数字，而是为每个位置保留碱基身份。
  - 例如：

```
	A C G T A C G T
```

    可以编码为：

```
	A  1 0 0 0 1 0 0 0
	C  0 1 0 0 0 1 0 0
	G  0 0 1 0 0 0 1 0
	T  0 0 0 1 0 0 0 1
```

![[Pasted image 20260918200326.png]]
    最后会形成这个矩阵，里面包含样本数，碱基种类，每条序列长度
    优点：碱基顺序和位置准确，信息量大
    缺点：没有告诉生物学语义信息，需要模型自己学习
4：token+embedding    用途：基础模型
    不直接把每个碱基作为最终模型表示，而是切词元
    常见切分方式为，单碱基token，固定K-mer token，通过学习得到不同长度的片段表示，例如我爱基因组学这句话，学习之后就切为，我|爱|基因组学 三个token
    切完词元后进行embedding——把离散的token映射成连续的可学习向量
    例如：
`
	token "ACG"
	      ↓ 	[0.12, -0.31, 0.87, ...]
	`
    这个向量并不是人工规定的。
    它会受到训练目标的塑造。
    也就是说：
`
	训练数据 + 训练目标
	        ↓
	学习embedding
	        ↓
	形成适合模型任务的向量表示
	`
    因此，embedding是一种：
     **离散符号 → 连续向量空间**的映射。
    需要注意：
     **embedding空间中的“相似”不自动等于生物学意义上的“等价”。**
    ==是否具有生物学意义，还需要进一步验证。==

### 未知、掩蔽与缺失

- 1：N / 未知碱基
  - 表示：
  - 测序或参考信息无法确定。
  - 它不应该简单地被当成某一个真实碱基。
- 2：Mask / 掩蔽
  - 表示：
  - 主动隐藏某段序列，或者该区域被认为低可信。
  - 和“未知”不是同一个概念。
- 3: Missing / 缺失值
  - 表示：
  - 某个样本的某项数据没有被观测到。
  - 例如缺失表型或缺失基因型。

0可能是合法的生物学状态，也可能只是缺失值占位符，需要通过数据契约明确区分。

## 问题须在机器学习前定义

为了让机器学习有意义，解决真正的问题，不过拟合，假拟合，假结果。
我们需要在机器学习训练前定义**样本、标签、划分、基线和指标**
一个完整、可信的机器学习任务，在训练之前就必须定义：**sample X Y**
![[Pasted image 20260918203525.png|484]]
![[Pasted image 20260918204550.png|341]]==整个流程==
1：sample
**一个sample必须对应一个明确的、可定义的独立观察单位。**
![[Pasted image 20260918203705.png|377]]
sample定义决定X的方向、y的含义、数据划分策略以及最终能支持的结论。
2：X
模型看到的输入
3：Y
模型需要预测的目标
拿到y以后至少需要问：

1. 是谁测的？

2. 在什么环境下测的？

3. 什么组织、什么发育时期？

4. 正负样本如何定义？

5. 缺失值到底代表什么？

6. 有没有批次效应？

7. 能否迁移到新的群体或环境？

例如：

> “高产”并不是脱离条件的绝对标签。

它可能取决于：

- 年份

- 地点

- 栽培条件

- 对照品种

- 使用的统计模型

**模型学习的是“在特定标签定义下的数据规律”，而不是脱离实验条件的绝对真理。**
4：设置数据划分
将全部数据划分为

- 训练集 用于拟合模型参数
- 验证集 用于调参与模型选择
- 测试集 用于最后评价
  ==数据划分原则：划分方式必须匹配你真正想测试的外推能力==
  比如你以染色体划分数据，测试时就看能否推广到未见过的基因组区域
  以按环境/年份划分，测试时就看能否推广到新的环境
  **模型训练时因为数据划分产生的问题**
  ① Data leakage：数据泄露
      测试集信息以直接或间接方式进入训练过程。导致测试性能虚高，认为泛化能力好。
      常见来源包括：
  - 同源序列或家族成员同时进入训练和测试
  - 技术重复跨越训练集和测试集
  - 相邻重叠窗口被当作独立样本
  - 使用全数据进行特征筛选后再划分
  - 其他形式的测试信息提前进入模型开发流程
    ② Shortcut：捷径
        测试信息进入了训练过程，模型利用了与真正目标无关、但恰好能帮助预测的信号。==“做了原题”==
        可能来源：
  - GC组成
  - 文件名
  - 批次
  - 亲缘关系
  - 样本来源
    5：Baseline：模型基线 一个简单可复现的参照模型
    帮助我们回答，现在的复杂模型到底帮助我们增加了什么效果
    基线模型可能利用线性回归，随机森林，利用GC比例或者k-mer等低信息量的信息进行构建。
    7：OOD：分布外预测
    模型面对训练分布之外的数据进行预测，用来测试更强的外推能力
    Test 是“我故意藏起来，用来检验模型的数据”；OOD 是“藏起来的数据不仅没见过，而且和训练数据不是一个分布”
