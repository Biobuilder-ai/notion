# 03 Linux 常用命令速查

## 目录与文件操作

| 命令 | 作用 |
|------|------|
| `pwd` | 显示当前路径 |
| `ls` | 列出文件 |
| `ls -a` | 列出所有文件（含隐藏 . 文件） |
| `ls -la` | 详细列出所有文件 |
| `cd ~` | 回到主目录 |
| `cd ..` | 回到上一级 |
| `mkdir 目录名` | 创建文件夹 |
| `touch 文件名` | 创建空文件 |
| `rm 文件名` | 删除文件（永久删除，无回收站！） |
| `rm -i 文件名` | 安全删除（会问你是否确认） |
| `rm -r 目录名` | 删除文件夹（递归删除） |
| `mv 旧名 新名` | 改名或移动 |
| `cp 源 目标` | 复制 |

## 查看文件内容

| 命令 | 作用 |
|------|------|
| `cat 文件` | 打印全部内容 |
| `head -n 20 文件` | 看前 20 行 |
| `tail -n 20 文件` | 看后 20 行 |
| `less 文件` | 分页浏览（q 退出，空格翻页） |

## 写入文件

| 命令 | 作用 |
|------|------|
| `echo "内容" > 文件` | 覆盖写入 |
| `echo "内容" >> 文件` | 追加写入 |
| `nano 文件` | 编辑器打开（Ctrl+O 保存，Ctrl+X 退出） |

## 其他常用

| 命令 | 作用 |
|------|------|
| `clear` | 清屏 |
| `exit` | 退出终端 |
| `命令 --help` | 查看命令帮助 |
| `grep "关键词" 文件` | 搜索关键词 |
| `wc -l 文件` | 统计行数 |
| `sudo apt install 包名 -y` | 安装软件 |

## 注意事项

- rm 删除的文件没有回收站，永久消失
- 切换分支前先 `git status` 确认没有未提交的修改
